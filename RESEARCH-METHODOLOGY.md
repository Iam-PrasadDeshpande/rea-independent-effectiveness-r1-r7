# Research methodology

The unit of comparison is one bounded task within one application. A uses ordinary Codex inspection, B adds direct conventional tools, and C adds REA. R1 has A/C only. Different studies have different permitted common tools, oracles, model/recovery histories and feature boundaries. There is no pooled accuracy, universal architecture score or seven-study causal speed comparison.

Reference behavior and hidden contracts were prepared before the selected valid investigations, with additive transport/controller changes retained where disclosed. New conversations and recorded tool/mount controls separated investigator inputs from reference materials and peer outputs. This is evidence of the tested boundaries, not proof against model pretraining or every hostile host escape.

Working submissions were evaluated separately from their architecture reports. The publication mission verifies retained bytes and judgments; it reruns no experiment, oracle, reconstruction or provider analysis. Historical architecture grades are model/coordinator assessments unless a source check is explicitly described. No new human-gold validation is claimed.
