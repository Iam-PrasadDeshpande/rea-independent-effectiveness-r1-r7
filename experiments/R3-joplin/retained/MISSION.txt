STAGE 1 — SOURCE AND ARTIFACT PREFLIGHT

1. Pin exact Joplin source commit and release assets.
2. Verify the applicable licenses and distribution terms.
3. Identify an official packaged Windows desktop artifact.
4. Verify its published SHA-256 and available signatures.
5. Determine whether app.asar can be extracted read-only.
6. Inspect real semantic-search implementation in the
   evaluator-only reference source.
7. Verify REA's static Electron analysis capability.
8. Identify actual runtime/model prerequisites.
9. Document source and artifact relationships.

Do not assume that release JavaScript is minified.
Measure actual artifact complexity and analysis coverage.

STAGE 2 — FROZEN EVALUATION ORACLE

- Search entry points
- Settings and eligibility rules
- Embedding provider selection
- Background indexing behavior
- Local index persistence
- Similarity retrieval
- Result aggregation
- Error and fallback behavior
- Reindexing and invalidation behavior

behavioral scenarios where independently executable
validation is technically feasible.
