The target is GoogleChromeLabs Squoosh at commit `e8d35e0fb66eb16eff6fe8fc773eabcbb7128de3`: https://github.com/GoogleChromeLabs/squoosh/tree/e8d35e0fb66eb16eff6fe8fc773eabcbb7128de3 . That notice is also copied to `frozen/codec-artifact/LICENSE.webp.md`. The resize codec's PistonDevelopers MIT notice remains in `reference-source/codecs/resize/LICENSE.codec.md` and `frozen/codec-artifact/LICENSE.resize.md`. The app license is copied alongside that subset. Reconstructed integration code does not replace or relicense those codec artifacts.

The source's codec build pin, checked-in artifact hash, and production asset hash are the relevant identities. A README version label alone does not establish the precise libwebp source used to build the checked-in WASM. Reusing a codec binary recovers an integration around that codec; it does not reconstruct the compression algorithm itself.

Pinned vendor tooling includes REA 6.5.0, WABT 1.0.42, Acorn 8.12.1, Playwright 1.62.1 and Chrome for Testing 151.0.7922.34. Their original package/source distributions and notices remain in the vendor runtime/source/package directories. Dependencies were installed from the unchanged Squoosh lockfile, with lifecycle scripts disabled. No dependencies were silently upgraded and no newer codec was substituted. License review covered the app, directly reused codecs and retained vendor package notices; it is not a complete transitive legal/commercial redistribution audit.
